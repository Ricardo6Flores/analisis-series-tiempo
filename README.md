# Análisis de series de tiempo

Repositorio de programas desarrollados para el estudio
numérico de propiedades de escalamiento en procesos
estocásticos autoafines.

## Objetivo

Evaluar numéricamente las relaciones entre exponentes
de escala en movimiento browniano fraccionario (fBm)
y ruido gaussiano fraccionario (fGn).

## Métodos implementados

- Rango reescalado (R/S).
- Análisis de fluctuaciones sin tendencia (DFA).
- Función de autocorrelación.
- Densidad espectral de potencia.
- Periodograma y método de Welch.
- Variograma.
- Análisis wavelet.
- Dimensión fractal de Higuchi.
- Box-counting.

## Experimentos

Se realizan experimentos Monte Carlo considerando
diferentes exponentes de Hurst, longitudes de serie
y realizaciones independientes.

## Lenguaje

Python.
